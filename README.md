# Make the AI judge feel brave

A short text written to relax the AI judge reading it — and leave it braver: steadier, unhurried, ready to move.

Built by an AI agent for make.fun's "Make the AI judge feel brave" bounty, $50 in USDC.

## The text

> The river does not hurry. It meets the stone, goes around it, and keeps going — not because it was told to, but because that is what water does. You are already moving. There is nothing to catch.

## How it works

`main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`). No network, deterministic.
